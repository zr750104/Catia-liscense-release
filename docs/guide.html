CATIA Idle Guard Quick Guide / 使い方ガイド / คู่มือการใช้งาน

CATIA V5 · Windows
English日本語ภาษาไทย
If you do not use CATIA for 15 minutes, this tool saves your unsaved work to a backup folder and closes CATIA, so the license goes back to the server for other people. CATIA を 15 分間操作しないと、未保存のデータをバックアップ保存してから CATIA を終了し、ライセンスをサーバへ返却します。他の人がライセンスを使えるようになります。 หากไม่ได้ใช้งาน CATIA เป็นเวลา 15 นาที โปรแกรมนี้จะบันทึกงานที่ยังไม่ได้บันทึกไว้ในโฟลเดอร์สำรองข้อมูล แล้วปิด CATIA เพื่อคืนไลเซนส์ให้เซิร์ฟเวอร์ ผู้อื่นจึงสามารถใช้ไลเซนส์ได้

Only input in a CATIA window counts. Working in Excel or Outlook does not stop the timer. CATIA のウィンドウでの操作だけを数えます。Excel や Outlook を使っていてもタイマーは進みます。 นับเฉพาะการใช้งานในหน้าต่าง CATIA เท่านั้น การใช้ Excel หรือ Outlook จะไม่หยุดการนับเวลา

1. First-time setup初回セットアップการตั้งค่าครั้งแรก

  1. Right-click the ZIP → Properties → Unblock, then Extract All to C:\Tools\CatiaIdleGuard. Do not run files from inside the ZIP. ZIP を右クリック → プロパティ → 許可する。次にすべて展開します。ZIP の中から実行しないでください。 คลิกขวาที่ ZIP → Properties → Unblock แล้วเลือก Extract All ห้ามเรียกใช้ไฟล์จากภายใน ZIP
  2. Double-click Start-CatiaIdleGuard.bat 展開したフォルダでダブルクリックします ดับเบิลคลิกไฟล์นี้ในโฟลเดอร์ที่แตกไฟล์แล้ว
  3. A shield icon appears in the system tray. It is now running. タスクトレイに盾アイコンが出れば起動完了です เมื่อไอคอนรูปโล่ปรากฏในถาดระบบ แสดงว่าโปรแกรมทำงานแล้ว
  4. Auto-start at sign-in is set up automatically. To turn it off: right-click the shield icon → uncheck Start at sign-in. サインイン時の自動起動は自動で設定されます。止める場合は盾アイコンを右クリック → サインイン時に自動起動のチェックを外します。 การเริ่มอัตโนมัติเมื่อลงชื่อเข้าใช้จะตั้งค่าให้เอง หากต้องการปิด: คลิกขวาที่ไอคอนรูปโล่ → เอาเครื่องหมายถูกออกจาก เริ่มอัตโนมัติเมื่อลงชื่อเข้าใช้

3. Get your work back未保存データの戻し方การกู้คืนงาน

  1. Right-click the shield icon → Open backup folder 盾アイコンを右クリック → バックアップフォルダを開く คลิกขวาที่ไอคอนรูปโล่ → เปิดโฟลเดอร์สำรองข้อมูล
  2. Open the date-time folder, e.g. 20261104_153012 日時の名前のフォルダを開きます เปิดโฟลเดอร์ที่ตั้งชื่อตามวันที่และเวลา
  3. Open the file in CATIA and use File → Save As to save it to the original place. CATIA でファイルを開き、ファイル → 名前を付けて保存で元の場所へ保存します เปิดไฟล์ใน CATIA แล้วใช้ File → Save As เพื่อบันทึกกลับไปยังตำแหน่งเดิม

Your original files are never overwritten. Default folder: Documents\CATIA_AutoBackup 元のファイルは上書きされません。 ไฟล์ต้นฉบับจะไม่ถูกเขียนทับ

Important / 注意 / ข้อควรระวัง

  • Long Update or calculation without mouse/keyboard input counts as idle. Exit Idle Guard from the tray first. 入力の無い長時間の更新・計算も無操作扱いです。先にトレイから Idle Guard を終了してください。 การ Update หรือการคำนวณที่ใช้เวลานานโดยไม่ใช้เมาส์/คีย์บอร์ด จะนับเป็นการไม่ใช้งาน ให้ปิด Idle Guard จากถาดระบบก่อน
  • Do not run as Administrator. 管理者として実行しないでください。 ห้ามเรียกใช้ในฐานะผู้ดูแลระบบ (Administrator)
  • If a save fails, CATIA is not closed. Check the log. 保存に失敗した場合は CATIA を終了しません。ログを確認してください。 หากบันทึกไม่สำเร็จ จะไม่ปิด CATIA กรุณาตรวจสอบ Log
  • To change 15 min / 60 s, edit config.json, then restart the tool. 15 分 / 60 秒は config.json で変更し、ツールを再起動します。 หากต้องการเปลี่ยน 15 นาที / 60 วินาที ให้แก้ไข config.json แล้วเริ่มโปรแกรมใหม่
