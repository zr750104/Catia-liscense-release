CATIA Idle Guard Quick Guide / 使い方ガイド

For CATIA V5 users / CATIA V5 利用者向け
Windows PowerShell 5.1
If you do not use CATIA for 15 minutes, this tool saves your unsaved work to a backup folder and closes CATIA, so the license goes back to the server for other people. CATIA を 15 分間操作しないと、未保存のデータをバックアップ保存してから CATIA を終了し、ライセンスをサーバへ返却します。他の人がライセンスを使えるようになります。

Only input in a CATIA window counts. Working in Excel or Outlook does not stop the timer. ／ CATIA のウィンドウでの操作だけを数えます。Excel や Outlook を使っていてもタイマーは進みます。

1. First-time setup初回セットアップ

  1. Copy the folder to your PC, e.g. C:\Tools\CatiaIdleGuardフォルダを PC にコピーします (例: C:\Tools\CatiaIdleGuard)
  2. Double-click Start-CatiaIdleGuard.batStart-CatiaIdleGuard.bat をダブルクリックします
  3. A shield icon appears in the system tray. It is now running.タスクトレイに盾アイコンが出れば起動完了です
  4. Auto-start at Windows sign-in (one time only):サインイン時に自動起動する設定 (1 回だけ実行):
    powershell -ExecutionPolicy Bypass -File "C:\Tools\CatiaIdleGuard\Install-Startup.ps1"

3. Get your unsaved work back未保存データの戻し方

  1. Right-click the shield icon → Open backup folder盾アイコンを右クリック → バックアップフォルダを開く
  2. Open the date-time folder, e.g. 20261104_153012日時の名前のフォルダを開きます (例: 20261104_153012)
  3. Open the file in CATIA and use File → Save As to save it to the original place.CATIA でファイルを開き、ファイル → 名前を付けて保存で元の場所へ保存します

Your original files are never overwritten. ／ 元のファイルは上書きされません。
Default folder: 既定の保存先: Documents\CATIA_AutoBackup

Important / 注意

  • Long Update or calculation without mouse/keyboard input counts as idle. Exit Idle Guard from the tray first.マウス/キー入力の無い長時間の更新・計算も無操作扱いです。先にトレイから Idle Guard を終了してください。
  • Do not run as Administrator.管理者として実行しないでください。
  • If a save fails, CATIA is not closed. Check the log.保存に失敗した場合は CATIA を終了しません。ログを確認してください。
  • To change 15 min / 60 s, edit IdleMinutes / WarningSeconds in config.json, then restart the tool.15 分 / 60 秒は config.json で変更し、ツールを再起動します。
