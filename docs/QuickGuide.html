CATIA Idle Guard

Quick Guide

For CATIA V5 users on Windows

If you do not use CATIA for 15 minutes, this tool saves your unsaved work to a backup folder and closes CATIA, so the license goes back to the server for other people.

How it works

No input in CATIA for 15 min
Warning dialog, 60 s countdown
Unsaved files saved to backup folder
CATIA closes
License returned

Only input in a CATIA window counts. Working in Excel or Outlook does not stop the timer.

1First-time setup

  1. Copy the folder to your PC, e.g. C:\Tools\CatiaIdleGuard
  2. Double-click Start-CatiaIdleGuard.bat
  3. A shield icon appears in the system tray. It is now running.
  4. Auto-start at Windows sign-in (one time only). Run this in PowerShell: 
    powershell -ExecutionPolicy Bypass -File "C:\Tools\CatiaIdleGuard\Install-Startup.ps1"

3Get your unsaved work back

  1. Right-click the shield icon, then click Open backup folder.
  2. Open the folder named with the date and time, e.g. 20261104_153012
  3. Open the file in CATIA and use File > Save As to save it to the original place.

Your original files are never overwritten. Default folder: Documents\CATIA_AutoBackup

Menu items are shown in English, Japanese and Thai.

Important

  • A long Update or calculation without mouse or keyboard input counts as idle. Exit Idle Guard from the tray first.
  • Do not run it as Administrator.
  • If a save fails, CATIA is not closed. Check the log.
  • To change 15 min / 60 s, edit IdleMinutes / WarningSeconds in config.json, then restart the tool.
